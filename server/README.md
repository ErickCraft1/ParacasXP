# Backend

Backend Express con estructura MVC y TypeScript.

La estructura principal se encuentra en `src/`:

- `config/`: configuración de la aplicación y servicios externos.
- `controllers/`: manejo de las peticiones HTTP.
- `middlewares/`: validaciones, autenticación y procesamiento previo/posterior.
- `models/`: entidades y acceso a datos.
- `routes/`: definición de endpoints.
- `services/`: lógica de negocio.
- `types/`: tipos TypeScript compartidos.
- `utils/`: funciones auxiliares.
